## Hola Mundo desde C++
Para escribir un hola mudno en c++ se hace de la siguiente manera
```c++
void solve(){
  cout << "Hola Mundo" << "\n";
}
```
## ¿Cómo ser bueno en física?

Tienes que hacer este comando en c++ y leer todo el texto que se genere sin equivocarte
```c++
#include <bits/stdc++.h>
using namespace std;

int main(){
  int t = 1e9;
  while(t--)cout << "pomporompompom" << "\n";
  return 0;
}
```
